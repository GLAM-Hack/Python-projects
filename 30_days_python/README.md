# 30 Days of Python

Репозиторий для прохождения курса **Asabeneh — 30 Days of Python**.
Здесь находятся задания, примеры и решения по дням курса (Day 1–Day 30).

Структура:

* Папки по дням: `Day_01`, `Day_02`, …
* Мои решения и краткие заметки внутри каждой папки.

Репозиторий обновляется по мере прохождения курса.
