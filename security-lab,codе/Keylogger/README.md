## 📘 Описание

Этот репозиторий содержит урезанную и безопасную версию исследовательского инструмента, созданного для демонстрации:

- обход антивирусов;
- перехвата клавиатуры;
- захвата экрана;
- отслеживания буфера обмена;
- взаимодействия с Telegram API;
- работы системного Task Scheduler;
- фоновых потоков;
- автозагрузка фаила при включения пк;
- скрытия консольного окна.
