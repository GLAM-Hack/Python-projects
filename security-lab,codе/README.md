## 📘 Описание

Этот репозиторий содержит урезанную и безопасную версию исследовательского инструмента, созданного для демонстрации:

- перехвата системных событий клавиатуры;
- создания скриншотов;
- отслеживания буфера обмена;
- взаимодействия с Telegram API;
- работы системного Task Scheduler (Windows);
- фоновых потоков;
- автозапуска скрипта при входе в систему;
- скрытия консольного окна;
- основ построения инструментов мониторинга для обучения кибербезопасности.

Код очищен от вредоносных элементов и может использоваться только в учебных целях.
